
# SpendWise Budget Tracker

## Project Description
SpendWise is a simple budget tracking application that helps users manage income and expenses.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage
- GitHub
- Netlify

## Features
- Add income and expenses
- Categorize transactions
- Calculate total income
- Calculate total expenses
- Display remaining balance
- Delete transactions
- Save transactions in browser storage
